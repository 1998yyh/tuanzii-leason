# RAG 术语表

> 全课核心术语速查。按主题分组，每条给出一句人话解释和首次出场的章节。

## 基础概念

| 术语 | 一句话解释 | 章节 |
| --- | --- | --- |
| RAG（检索增强生成） | 先检索相关资料，再让模型基于资料生成答案的技术范式 | 1 |
| LLM（大语言模型） | 通过预测下一个词来工作的超大参数量语言模型 | 1 |
| Token | 模型处理文字的最小单位，中文约 1 汉字 1–2 个 | 1 |
| 上下文窗口 | 模型一次能看到的 token 总量上限 | 1 |
| 幻觉（Hallucination） | 模型生成看似合理实则错误内容的现象，机制的副产品 | 1 |
| 知识截止 | 训练数据的时间边界，之后的信息模型一概不知 | 1 |
| 参数化记忆 | 压缩在模型参数里的知识，训练结束即冻结 | 1 |
| 非参数化记忆 | 存放在外部（数据库/文档库）、用的时候现查的知识 | 1 |
| Prompt Engineering | 通过设计输入引导模型输出的做法，知识放提示词里 | 1 |
| Fine-tuning（微调） | 用自有数据继续训练模型参数，擅长教行为不擅长灌知识 | 1 |

## 索引期

| 术语 | 一句话解释 | 章节 |
| --- | --- | --- |
| 索引期 | 文档进来时跑的预处理流水线（加载→分块→向量化→入库） | 2 |
| 查询期 | 用户提问时跑的问答流水线（检索→组装→生成） | 2 |
| Chunking（分块） | 把长文档切成语义聚焦的小块 | 4 |
| Chunk Size / Overlap | 块的目标长度 / 相邻块之间重复保留的内容 | 4 |
| 递归切分 | 按「段落→句子→字符」优先级逐级降级的切分策略，工业默认 | 4 |
| 语义稀释 | 块内主题过多导致向量「四不像」，检索匹配度下降 | 3 |
| 元数据（Metadata） | 挂在块上的出身信息（文档、位置、标题），过滤与溯源的基础 | 4 |

## 向量与检索

| 术语 | 一句话解释 | 章节 |
| --- | --- | --- |
| Embedding（嵌入） | 把文字映射成向量（一串数字）的技术 | 3 |
| 稠密向量 | 各维度几乎全非零、语义弥散分布的向量，Embedding 的产物 | 3 |
| 稀疏向量 | 维度巨大但绝大多数为零、维度对应具体词的向量 | 3 |
| 语义检索 | 按向量距离找「意思相近」的内容，而非字面匹配 | 3 |
| 余弦相似度 | 比较两向量方向夹角的相似度度量，-1 到 1 | 3 |
| ANN（近似最近邻） | 用一点精度换数量级速度的检索方式 | 3 |
| HNSW | 多层图结构的 ANN 索引，pgvector 首选 | 3、5 |
| pgvector | 把 PostgreSQL 变成向量数据库的扩展 | 5 |
| `<=>` `<->` `<#>` | pgvector 的余弦距离、L2 距离、负内积操作符 | 5 |

## 查询期优化

| 术语 | 一句话解释 | 章节 |
| --- | --- | --- |
| 查询改写 | 借对话历史把指代问题补全成自包含检索句 | 6 |
| 查询扩展 / 多路召回 | 一个问题生成多个问法分别检索，合并结果 | 6 |
| HyDE | 先让模型编个假答案，用假答案的向量去检索 | 6 |
| 子查询分解 | 把复合问题拆成可独立检索的子问题 | 6 |
| BM25 | 关键词检索的经典打分函数（IDF 稀罕度 + TF 饱和 + 长度归一） | 7 |
| 混合检索（Hybrid Search） | 向量路 + 关键词路两路召回，各取所长 | 7 |
| RRF（倒数排名融合） | 不看分数只看名次的融合算法，1/(k+rank) | 7 |
| Re-ranking（重排序） | 粗排召回后用精准模型对候选重新打分排序 | 8 |
| Cross-Encoder | 把查询和文档拼在一起输入模型、直接判相关度的结构 | 8 |
| 双塔结构 | 查询和文档各自独立编码的 Embedding 结构，快但丢交互信息 | 8 |

## 生成与评估

| 术语 | 一句话解释 | 章节 |
| --- | --- | --- |
| Lost in the Middle | 模型对 Prompt 中间部分内容利用最差的现象 | 9 |
| 引用溯源 | 答案标注出自哪块资料，可回看原文 | 9 |
| 拒答 | 检索不到相关内容时明说不知道，不硬答 | 9 |
| SSE | 基于 HTTP 的单向流式推送协议，问答产品标配 | 9、14 |
| Recall@K | 相关块里有多少进了前 K 名，管「漏不漏」 | 10 |
| MRR | 第一个相关块排名的倒数均值，管「前不前」 | 10 |
| NDCG | 带相关性分级和位置折扣的排序质量指标 | 10 |
| Faithfulness（忠实度） | 答案论断能否被资料支撑，RAG 头号生成指标 | 10 |
| RAGAS | Python 生态的 RAG 评估框架 | 10 |
| badcase 归因 | 把失败案例按「检索漏/检索错/生成错」分责的迭代法 | 10 |

| 术语 | 一句话解释 | 章节 |
| --- | --- | --- |
| GraphRAG | 抽取实体关系建知识图谱，补全局性与关系性问题 | 11 |
| Agentic RAG | LLM 在决策回路里决定检索动作，补多步推理 | 11 |
| Self-RAG | 生成过程中自我评估「要不要检索、答案忠不忠」 | 11 |
| CRAG | 检索质量不达标时主动纠正（重查/补查）的变体 | 11 |
