章节目录

  1. 第 1 章 LangChain 是什么：从「会调 API」到「会做 AI 应用」 从裸调 API 的痛点出发，认识 LangChain 的生态版图与它在 AI Agent 时代的角色。
  2. 第 2 章 核心三件套与 LCEL：模型、提示词、输出解析 掌握 Runnable 协议与管道组合，把调模型拆成可替换的部件。
  3. 第 3 章 给模型补上知识：RAG 与检索增强实战 从文档加载到向量检索，建成一条可问答的 RAG 链。
  4. 第 4 章 工具调用与 Agent：LangChain 的天花板在哪里 手写 Agent 循环看清机制，理解为什么复杂编排需要 LangGraph。
  5. 第 5 章 LangGraph 是什么：从链到图的必然 把手写 Agent 循环抽象成状态、节点、边，理解图编排的设计动机。
  6. 第 6 章 第一张图：State、Node、Edge 实战 跑通最小图，掌握 Reducer 与状态更新语义。
  7. 第 7 章 分支与循环：条件边让图活起来 用条件边重建 Agent 循环，掌握循环终止与并行分支。
  8. 第 8 章 记忆与持久化：Checkpointer 让图记住一切 实现可重启续聊的 Agent，理解快照、回放与长短期记忆分层。
  9. 第 9 章 人在回路：中断、审批与流式输出 用 interrupt/resume 实现人工审批，掌握三种粒度的流式输出。
  10. 第 10 章 进阶：多 Agent、子图与生产化 Supervisor 多 Agent 协作、子图封装、LangSmith 观测与部署决策。
  11. 第 11 章 项目导览：需求、架构与工程初始化 解读 Ticket Polit 需求与技术方案，搭好前后端骨架并联通。
  12. 第 12 章 后端地基：数据模型、鉴权与核心 API 按后端技术方案落地领域模型与核心业务接口。
  13. 第 13 章 后端 AI 内核：LangGraph Agent 工作流落地 把 AI 需求翻译成图设计，实现带持久化与流式输出的 Agent 工作流。
  14. 第 14 章 前端实现：页面、状态与 AI 交互体验 按前端技术方案实现全部页面与流式 AI 交互体验。
  15. 第 15 章 联调、测试、部署与复盘 端到端联调排错、测试与部署落地，复盘全课技术决策。
